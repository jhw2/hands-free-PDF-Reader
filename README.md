# Motion PDF Reader

오른쪽/왼쪽 고개 회전으로 PDF 페이지를 넘길 수 있는 브라우저 기반 뷰어 예제입니다.

## 사용 방법

1. `npm install`
2. `npm run dev`
3. 브라우저에서 `http://localhost:3000` 접속
4. `PDF 파일 선택` 버튼으로 PDF를 업로드합니다.
5. 웹캠 접근을 허용합니다.
6. 고개를 오른쪽으로 돌리면 다음 페이지, 왼쪽으로 돌리면 이전 페이지로 이동합니다.

## 기능

- `pdf.js` 기반 PDF 렌더링
- `MediaPipe FaceMesh` 기반 얼굴 랜드마크 추적
- 고개 회전을 감지하여 페이지 이동

## 확장

- 얼굴 인식 대신 포즈 감지를 쓰거나, 화면 중앙에서 고개를 흔들어서 작동하게 바꿀 수 있습니다.
- `gestureInfo` 상태를 추가해 더 다양한 제스처를 표현할 수 있습니다.
